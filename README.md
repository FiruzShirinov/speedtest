# speedtest

Консольный скрипт на Python, который замеряет скорость скачивания: делает к заданному адресу
N запросов (по умолчанию 10) **последовательно**, каждый раз дочитывая ответ до конца, и печатает
среднее время запроса, общий объём скачанного и скорость.

## Требования

Python 3.8+. Сторонних зависимостей нет, используется только стандартная библиотека (`urllib`).

## Запуск

```bash
python speedtest.py <URL>
```

Пример:

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

```
Request  1:   10.49 MB in 4.163 s
Request  2:   10.49 MB in 3.801 s
...
Request 10:   10.49 MB in 3.722 s

Requests:         10
Average time:     3.888 s
Total downloaded: 104.86 MB (104857600 bytes)
Download speed:   21.57 Mbit/s
```

Необязательные параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `-n`, `--count` | `10` | количество запросов |
| `-t`, `--timeout` | `30` | таймаут одного запроса, секунды |

Если какой-то запрос завершился ошибкой (сеть, DNS, HTTP 4xx/5xx, таймаут), скрипт печатает
причину и выходит с кодом `1`.

## Единицы измерения

- **Время** — секунды (`s`).
- **Объём** — десятичные единицы: 1 KB = 1 000 байт, 1 MB = 1 000 000 байт. В скобках
  выводится точное число байт.
- **Скорость** — **мегабиты в секунду (Mbit/s)**, 1 Mbit = 1 000 000 бит. Так скорость указывают
  провайдеры и сервисы вроде Speedtest, поэтому результат легко сравнить.

## Как считается

- Время каждого запроса измеряется `time.perf_counter()` от отправки запроса до прочтения
  последнего байта тела. В это время входят DNS, установка TCP/TLS-соединения и ожидание
  первого байта, то есть это полное время запроса, которое видит клиент.
- **Среднее время** = сумма времён / число запросов.
- **Скорость** = общий объём в битах / суммарное время всех запросов.
- Тело читается кусками по 64 KB, поэтому большой файл не держится в памяти целиком.
- Запрос отправляется с заголовком `Cache-Control: no-cache`, чтобы промежуточные кэши
  не отдавали сохранённую копию.

## Ограничения

- Каждый запрос открывает новое соединение, поэтому на маленьких файлах большая часть времени
  уходит на рукопожатие, и скорость получается заниженной. Для осмысленного результата лучше
  брать файл от нескольких мегабайт.
- Некоторые сайты (например, Wikimedia) отвечают `429 Too Many Requests` на запросы скриптов.
  Для проверки удобно использовать специальные тестовые файлы, например
  `https://proof.ovh.net/files/10Mb.dat`.
